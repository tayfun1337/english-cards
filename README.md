# English Cards

Английский по карточкам со свайпами: слова и предложения уровней A0–C2, британская транскрипция,
перевод на русский, интервальное повторение и словарь выученных. Работает без интернета, прогресс хранится
только на вашем компьютере.

## Скачать

Последняя версия — на странице **[Releases](https://github.com/tayfun1337/english-cards/releases/latest)**.

| Система | Файл |
|---|---|
| Windows 10 / 11 | `EnglishCards-<версия>-windows.exe` |
| Mac с Apple Silicon (M1–M4) | `EnglishCards-<версия>-mac-arm64.dmg` |
| Mac с Intel | `EnglishCards-<версия>-mac-x64.dmg` |

Какой у вас Mac: меню  → «Об этом Mac». Если там написано «Чип Apple M…», вам нужен `arm64`, если «Процессор Intel» — `x64`.

### Windows

Запустите exe — установка не нужна, файл можно держать где угодно.

Если появится «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**:
у приложения нет платной цифровой подписи.

### Mac

1. Откройте dmg и перетащите **English Cards** в папку «Программы».
2. При первом запуске macOS скажет, что не может проверить разработчика: у приложения нет платной подписи Apple.
   Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **Всё равно открыть**
   и подтвердите.

Если macOS пишет, что приложение «повреждено», выполните в Терминале и запустите снова:

```bash
xattr -dr com.apple.quarantine "/Applications/English Cards.app"
```

## Как пользоваться

| Действие | Мышь / трекпад | Клавиша |
|---|---|---|
| Знаю | перетащить карточку вправо | → |
| Повторить | перетащить карточку влево | ← |
| Перевернуть карточку | нажатие | Пробел |
| Отменить последний ответ | кнопка ↶ | Ctrl+Z / ⌘Z |
| Показать / скрыть транскрипцию предложения | кнопка на карточке | T |

Карточку «Повторить» приложение покажет снова через 1, 3, 7, 14 и 30 дней. После последнего интервала
она попадает в словарь выученных.

**Прогресс** хранится в `%APPDATA%\English Cards` (Windows) или `~/Library/Application Support/English Cards` (Mac)
и не пропадает при обновлении. Чтобы перенести его на другой компьютер, используйте
«Настройки → Сохранить копию в файл» и «Загрузить копию из файла».

**Озвучка** использует голоса системы. Если в настройках написано «В системе нет английского голоса», добавьте его:

- Windows: *Параметры → Время и язык → Речь → Добавить голоса → English (United Kingdom)*;
- Mac: *Системные настройки → Универсальный доступ → Устный контент → Системный голос → Управлять голосами → English (UK)*.

- Транскрипция — [ipa-dict](https://github.com/open-dict-data/ipa-dict), MIT.
- Предложения и примеры с переводами — [Tatoeba](https://tatoeba.org), CC BY 2.0 FR.
